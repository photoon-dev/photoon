Coloque aqui os `.dc.html` exportados do projeto Claude Design
(2261d6c3-e9d9-4945-96b3-80fb194e3448), que esta em outra conta e por isso
nao pode ser lido pela API desta sessao.

- Cliente Entrar.dc.html           -> src/app/entrar/page.tsx + components/FormEntrar.tsx
- Cliente Meus projetos.dc.html    -> src/app/meus-projetos/page.tsx + components/CardProjeto.tsx
- Cliente Detalhe do projeto.dc.html -> src/app/projetos/[id]/page.tsx
- Cliente Editor.dc.html           -> src/app/projetos/[id]/editor/page.tsx
- logo.svg / logo-lockup.svg       -> public/
